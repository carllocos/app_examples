# Toggle LED Deactivate

The `toggle_led_deactivate` directory contains an AssembylScript application that toggles an LED when pressing buttons.
Another button will completely disable the use of interrupts.
The application was written to target the M5StickC pin layout and can be changed to target other ESP32 boards.

The `toggle_led_deactivate` project directory contains the following files:
- `src/arduino.ts`: an AS source file that abstracts the use of the WARDuino primivites.
- `src/toggle_led_deactivate.ts`: the AS source file that uses the `arduino.ts` and implements the toggling behaviour.
- `wasm/toggle_led_deactivate.wasm`: the Wasm module obtained after compiling the `toggle_led.ts`
- `wasm/mappings.json`: the extract mappings from the Source Map Spec debugging information generated by the AssemblyScript compiler. The creation of this file is optional but recommended as it eases the creation of tools for AssemblyScript. See tutorials for an explanation on how to generate this file.
- `wasm/config.json` a configuration file to clean the source mappings when producing the `mappings.json`


The `toggle-led.wasm` was compiled using AssemblyScript `Version 0.27.5` using the following command:
```bash
asc src/toggle_led_deactivate.ts --sourceMap --debug -o wasm/toggle_led.wasm
```

Alternatively, execute `npm run build` to build the wasm


The `mappings.json` got produced using the wasmito CLI command. Assuming wcli points to the CLI
```bash
cd wasm/
wcli sourcemap -s toggle_led_deactivate.wasm.map -c config.json toggle_led_deactivate.wasm mappings.json
```
